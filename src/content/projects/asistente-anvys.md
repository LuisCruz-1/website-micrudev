Asistente ANVYS explora el uso de inteligencia artificial dentro del contexto educativo para responder consultas relacionadas con el proceso de admisiones del Colegio ANAVI.

> El objetivo no era crear un chatbot genérico, sino un asistente preparado con información específica de la institución y capaz de ejecutar funciones concretas.

## Conocimiento especializado

El asistente utiliza la API de OpenAI y trabaja con información de admisiones proporcionada para el proyecto. De esta manera, las respuestas se mantienen enfocadas en el contexto que necesitan las familias interesadas.

## Dos formas de conversar

La experiencia fue planteada con dos modos de interacción para adaptarse a diferentes momentos de uso.

### Chat

Permite escribir preguntas y mantener una conversación progresiva sobre requisitos, información y dudas de admisión.

### Voz

Ofrece una alternativa de interacción hablada para realizar consultas sin depender exclusivamente del teclado.

## Funciones e integración

Además de responder preguntas, el asistente puede ejecutar funciones específicas definidas para la solución. Python y FastAPI articulan esta capa de integración con el modelo de inteligencia artificial.

El proyecto funciona como una exploración aplicada de IA conversacional, voz y automatización dentro de un único punto de contacto.
