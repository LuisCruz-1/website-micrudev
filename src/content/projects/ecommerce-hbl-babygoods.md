La plataforma de comercio electrónico de HBL Babygoods fue planteada como una solución completa y escalable para una empresa especializada en productos para bebés.

## El catálogo como núcleo

La tienda organiza un catálogo detallado en el que cada producto puede presentar variantes. La experiencia debía comunicar estas opciones claramente y acompañar al comprador durante todo el proceso de selección.

## Capacidades comerciales

- Catálogo de productos con variantes.
- Flujo para compras al por mayor.
- Cálculo dinámico de costos de envío.
- Múltiples opciones de pago en línea.
- Experiencia adaptable a dispositivos móviles y escritorio.

## Una base preparada para crecer

Next.js se utilizó para construir la experiencia de compra y Tailwind CSS para desarrollar la interfaz. Stripe forma parte de la capa de pagos y Vercel de la infraestructura de publicación.

La arquitectura permite mantener separadas la presentación del catálogo, las reglas comerciales y el proceso de pago, facilitando la evolución de la tienda conforme cambian las necesidades del negocio.
