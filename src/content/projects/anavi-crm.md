ANAVI CRM es una aplicación de gestión integral creada para reunir varios procesos críticos del Colegio ANAVI dentro de una misma plataforma.

## Un sistema, varias áreas

El proyecto se organizó alrededor de tres áreas principales y un módulo adicional de atención a familias.

### Admisiones

El módulo concentra la información necesaria para acompañar y organizar el proceso de admisión de nuevos estudiantes.

### Gestión de vacacional

La plataforma incorpora el manejo de la operación relacionada con el programa vacacional, evitando que su información permanezca aislada del resto de procesos.

### Inventario

El inventario forma parte del mismo entorno administrativo, facilitando el registro y la consulta de los recursos gestionados por la institución.

### Solicitudes de padres de familia

Un módulo adicional permite manejar las solicitudes recibidas de padres de familia y mantenerlas dentro de un flujo centralizado.

## Arquitectura del proyecto

La interfaz fue desarrollada con React y conectada a una API en Express. PostgreSQL organiza la información de los diferentes módulos y AWS proporciona la infraestructura utilizada por la solución.

Esta separación permite que cada área evolucione sin perder la visión integral del sistema.
